# Brand assets used in Phase 1

Source: CX83 Studio 0.8.2 draft archive, `CX83_Studio_082_Brand_Assets_DRAFT.zip`, retained in the owner's CX83 Labs Library.

`logo-light.svg` uses the paths, positions, fills and dimensions from `assets/logo/master/primary.svg`.
`logo-dark.svg` uses the paths, positions, gradient stops, fills and dimensions from `assets/logo/master/full-dark.svg`.
`symbol-showcase.svg` uses the geometry, gradient stops, stroke and dimensions from `assets/logo/master/symbol-showcase.svg`.

The SVGs were normalized for web delivery. The selected geometric shape and custom outlined lettering are preserved. These source assets are Studio draft output, not a newly approved final Studio release. Do not redraw, typeface-substitute, or invent a different logo. Future replacements must follow owner review.

The already selected homepage image `cx83-labs-hero.avif` remains unchanged.

Do not add new brand colors to individual pages. Use the semantic variables and shared classes in `src/app/(frontend)/cx83-brand.css`.
